# BUGS

Known bugs, seeded from the six-area project audit (level3d, actors, catrig, data, legacy, visual).

- **Owner tracks:** A = cat rig + cat actor, B = level, visuals, patrons and HUD, C = data, systems, docs and hygiene.
- **Task ids** refer to the implementation plan (A1–A18, B1–B15, C1–C10).
- **Status:** `open`, `fixed`, `verified`, `wontfix`, `skipped`. As of 2026-10-24 every audit row (BUG-001 to BUG-095) is `fixed`: tracks A, B and C reported their tasks done, and the final check passed (all five scenes boot headless with 0 errors, `validate_data` exits 0, `probe_core_loop` passes). Rows have not each been re-verified by hand, so none is marked `verified` yet.
- **Duplicates:** several audits reported the same defect, so some rows repeat. They are kept so each audit stays traceable, and should be closed together.
- **Triage rules:** see `Docs/BUG_TRIAGE.md`. Project risks are in `Docs/RISKS.md`.
